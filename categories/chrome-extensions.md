# Chrome Extensions Resources

## Productivity

- OneTab
  Link: https://www.one-tab.com
  Category: Tool
  Tags: chrome, tabs, productivity
  Notes: Reduces browser tab clutter by converting tabs into a restorable list.

- uBlock Origin
  Link: https://github.com/gorhill/uBlock
  Category: Tool
  Tags: chrome, privacy, browsing
  Notes: Efficient content blocker that improves browsing focus and performance.

  Category: Tool
  Tags: chrome, json, api
  Notes: Makes JSON responses easier to inspect directly in the browser.

- Wappalyzer
  Link: https://www.wappalyzer.com
  Category: Tool
  Tags: chrome, stack, discovery
  Notes: Identifies technologies used by websites for quick reconnaissance.
