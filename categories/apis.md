# API Resources

## Documentation

- OpenAPI Specification
  Link: https://swagger.io/specification/
  Category: Documentation
  Tags: api, openapi, contracts
  Notes: Standard reference for documenting and describing REST APIs.

- REST API Tutorial
  Link: https://restfulapi.net
  Category: Documentation
  Tags: api, rest, learning
  Notes: Practical reference for REST design principles and common patterns.

## Tools

- Postman
  Link: https://www.postman.com
  Category: Tool
  Tags: api, testing, collaboration
  Notes: Popular platform for sending requests, building collections, and testing APIs.

- Hoppscotch
  Link: https://hoppscotch.io
  Category: Tool
  Tags: api, lightweight, requests
  Notes: Fast web-based API client for quick request and response inspection.

- MockAPI
  Link: https://mockapi.io/
  Category: Tool
  Tags: api, mock, backend, testing
  Notes: Hosted mock API service for prototyping, testing, and frontend development.

- My JSON Server
  Link: https://my-json-server.typicode.com/
  Category: Tool
  Tags: api, mock, github, testing
  Notes: Quick way to turn a GitHub repository into a fake REST API for demos and prototypes.

- Google Cloud API Library
  Link: https://console.cloud.google.com/apis/library
  Category: Documentation
  Tags: api, google-cloud, catalog, cloud
  Notes: Central catalog for discovering and enabling Google Cloud APIs and services.

## Public Data APIs

- NASA EONET
  Link: https://eonet.gsfc.nasa.gov/
  Category: Documentation
  Tags: api, nasa, open-data, events
  Notes: Open NASA API for near real-time natural event metadata, categories, sources, and imagery-linked event data.

- OpenWeather
  Link: https://openweathermap.org/
  Category: Documentation
  Tags: api, weather, open-data, forecast
  Notes: Weather data platform with APIs for forecasts, current conditions, and environmental data.

- Public APIs
  Link: https://github.com/public-apis/public-apis
  Category: Documentation
  Tags: api, directory, open-data, github
  Notes: Large community-maintained directory of free and public APIs across many domains.

- News API
  Link: https://newsapi.org/
  Category: Documentation
  Tags: api, news, content, search
  Notes: API for searching headlines, publishers, and news content across sources.

- RoyaleAPI
  Link: https://royaleapi.com/
  Category: Documentation
  Tags: api, gaming, stats, reference
  Notes: Reference site and API resources for Clash Royale data, decks, and card insights.
