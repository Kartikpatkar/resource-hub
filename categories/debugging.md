# Debugging Resources

## Browser Debugging

- Chrome DevTools Documentation
  Link: https://developer.chrome.com/docs/devtools/
  Category: Documentation
  Tags: debugging, browser, devtools
  Notes: Official reference for inspecting DOM, network, performance, and memory.

- Firefox Developer Tools
  Link: https://firefox-source-docs.mozilla.org/devtools-user/
  Category: Documentation
  Tags: debugging, firefox, browser
  Notes: Useful alternative browser tooling documentation for frontend debugging.

## Application Debugging

- VS Code Debugging
  Link: https://code.visualstudio.com/docs/editor/debugging
  Category: Documentation
  Tags: debugging, vscode, workflow
  Notes: Covers breakpoints, launch configurations, and debugger setup.

- Node.js Debugging Guide
  Link: https://nodejs.org/en/docs/guides/debugging-getting-started/
  Category: Documentation
  Tags: debugging, nodejs, backend
  Notes: Good starting point for debugging JavaScript outside the browser.
